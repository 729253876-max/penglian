实际结果：

- 运行前以 `netstat -ano -p tcp` 确认 3100 无 `LISTENING`。
- 测试退出码 `0`，`1 passed` 测试文件、`1 passed` 测试。
- 创建人像任务返回 `201`，任务状态为 `AWAITING_CONFIRMATION`。

- 读取任务返回 `200`，终态为 `SUCCEEDED`。
- 读取事件返回 `200`，共 9 条，`nextSequence` 为 `9`，末项为
  `PREVIEW_READY`。
- 合法老照片契约在阶段 A API 边界返回 `422`，
  `code = STAGE_A_UNSUPPORTED_TOOL`。
- 测试关闭 Fastify 后 3100 无 `LISTENING`；仅出现正常 TCP `TIME_WAIT`。

排障记录：本轮最早一次受控后台启动因 WMI 进程树读取被拒绝，留下 Node
PID `10484` 占用 3100；`Get-NetTCPConnection` 在当前权限下漏报该监听，
`netstat -ano -p tcp` 成功定位。确认该 PID 的启动时间与本轮命令一致后仅清理
该 PID，再执行上述测试通过。后续端口前后置检查统一以 `netstat` 为准。

后续受控启动和 HTTP 冒烟必须从与自动化验证相同的源码目录执行：
