# B1 微信身份与授权 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不接入图片和供应商的前提下，实现正式微信身份映射、显式授权、2 小时访问令牌、30 天轮换刷新会话、最多 5 台设备、退出与注销入口，并强制用户资源归属。

**Architecture:** 保持 Fastify 模块化单体，新增身份、授权和会话模块；令牌使用 Node `crypto` 生成的高熵不透明值，数据库只保存 SHA-256 摘要。微信 `jscode2session` 通过可替换网关接入，单元测试使用模拟网关，MySQL 负责用户、身份、授权和会话持久化。

**Tech Stack:** TypeScript、Node.js、Fastify、Zod、MySQL 8、`mysql2`、Vitest、微信原生小程序。

## Global Constraints

- 正式 AppID 固定为 `wx4f7678cc595d276b`；AppSecret 只从部署密钥管理注入，不写入代码、测试、文档或 Git。
- OpenID 使用 HMAC-SHA-256 查找摘要和 AES-256-GCM 密文保存；两把 32 字节密钥均由部署密钥管理注入且分离使用。
- 首页和工具说明匿名可浏览；首次上传前才要求隐私确认和微信身份建立。
- 元数据清理授权不默认勾选；B1 只保存授权记录，B2 才执行图片上传。
- 访问令牌有效 2 小时；刷新会话最长 30 天，刷新成功后旧刷新凭证立即失效。
- 同一账号最多 5 个活跃设备会话；第 6 个登录撤销最久未使用会话。
- 支持退出当前设备、退出全部设备和服务端撤销。
- 注销后立即撤销全部会话并隐藏账号；活跃数据 24 小时清理、备份最长 30 天由 B4 实现。
- 任何真实账号登录、密钥使用、云资源开通或费用动作必须先征求用户同意。
- 使用国内 npm 镜像和锁文件；线上运行不依赖境外 SaaS。

```ts
export function issueToken(): IssuedToken {
  const raw = randomBytes(32).toString("base64url");
  return { raw, digest: createHash("sha256").update(raw).digest() };
}
```

Protect OpenID with separate lookup and encryption keys:

```ts
export function protectOpenId(openId: string, lookupKey: Buffer, encryptionKey: Buffer): ProtectedIdentity {
  const lookupHash = createHmac("sha256", lookupKey).update(openId).digest();
  const iv = randomBytes(12);
  const cipher = createCipheriv("aes-256-gcm", encryptionKey, iv);
  const ciphertext = Buffer.concat([cipher.update(openId, "utf8"), cipher.final()]);
  return { lookupHash, ciphertext: Buffer.concat([iv, cipher.getAuthTag(), ciphertext]) };
}
```
