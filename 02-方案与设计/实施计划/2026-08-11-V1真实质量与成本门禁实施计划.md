# V1 真实质量与成本门禁 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 B3 供应商适配前建立可复现的样片清单、盲测评分、缺陷判定、综合成本核算和 Go/No-Go 报告，阻止未经真实质量验证的供应商进入产品链路。

**Architecture:** 新建无外部依赖的内部 workspace 包 `@photo-ai/market-validation`，只处理匿名样片 ID、评分和成本数字，不接触图片文件、供应商密钥或网络。纯函数负责校验与聚合，CLI 只负责读取本地 JSON 并输出 JSON/Markdown；协议、空白模板和永久记录放入项目标准文档目录。

**Tech Stack:** TypeScript 5.9、Vitest 3、Node.js ESM、npm workspaces、Markdown、CSV/JSON。

## Global Constraints

- V1 工具固定为人像精修、画质增强、路人/杂物消除和老照片修复；创意生成不进入本计划。
- 首轮建议 100 张：40 张人像、20 张画质增强、20 张路人/杂物消除、20 张老照片；这是本轮配置，不是永久产品常量。
- 输入文件只允许匿名 `sampleId`、分类、评分和成本，不允许图片路径、图片 URL、OpenID、手机号、Token、Cookie、密钥或数据库 URL。
- 不安装新依赖，不联网，不调用供应商，不上传图片，不创建云资源，不产生费用。
- 人物身份/主体结构通过率最低 95%；严重缺陷率最高 5%；相对原图偏好最低 65%；相对竞品基线偏好最低 45%；愿意保存/分享最低 60%。
- 成本必须包含推理、审核、失败重试、存储、带宽、支付和退款损耗；贡献毛利必须大于 0 才通过成本门禁。
- 上述阈值是 Project-002 的内部止损线，不得表述为行业基准或直接写入生产商品配置。
- B1-ENV 仍为 NOT RUN；本计划通过不等于产品可发布，也不授权真实用户、真实图片、支付或投放。
- 所有代码步骤使用 TDD；每个任务单独提交；不得把主工作区 `05-输出与交付` 的未跟踪文件纳入提交。

`src/types.ts` 明确定义：

```ts
export type EvaluationTool =
  | "PORTRAIT_RETOUCH"
  | "QUALITY_ENHANCE"
  | "OBJECT_REMOVAL"
  | "OLD_PHOTO_RESTORE";

export interface EvaluationSample {
  sampleId: string;
  tool: EvaluationTool;
  identityApplicable: boolean;
  identityPass: boolean;
  severeDefect: boolean;
  preferredOverOriginal: boolean;
  preferredOverBenchmark: boolean;
  willingToSave: boolean;
  successfulDelivery: boolean;
  inferenceCostYuan: number;
  moderationCostYuan: number;
  retryCostYuan: number;
  storageCostYuan: number;
  bandwidthCostYuan: number;
  paymentFeeYuan: number;
  refundLossYuan: number;
  candidatePriceYuan: number;
}

export interface EvaluationConfig {
  minimumSamplesByTool: Record<EvaluationTool, number>;
  thresholds: {
    identityPassRate: number;
    severeDefectRate: number;
    preferredOverOriginalRate: number;
    preferredOverBenchmarkRate: number;
    willingToSaveRate: number;
  };
}

export interface GateResult {
  id: "COVERAGE" | "IDENTITY" | "SEVERE_DEFECT" | "ORIGINAL_PREFERENCE" |
    "BENCHMARK_PREFERENCE" | "SAVE_INTENT" | "CONTRIBUTION_MARGIN";
  actual: number;
  threshold: number;
  operator: ">=" | "<=" | ">";
  passed: boolean;
}

export interface GateReport {
  decision: "GO" | "NO_GO";
  sampleCount: number;
  successfulDeliveryCount: number;
  metrics: Record<string, number>;
  gates: GateResult[];
}
```

`evaluateGate` 必须：先验证唯一 ID、布尔字段、有限且非负成本；四类最小数量不足形成 `COVERAGE` 失败而不是抛错；身份率只以 `identityApplicable=true` 为分母；所有偏好率只以 `successfulDelivery=true` 为分母。贡献毛利按“成功样本候选售价总和 − 所有样本七项成本总和”计算，再除以成功交付数；这样失败调用和重试成本不会被排除。任一门禁失败即 `NO_GO`。

核心计算保持显式，不用模糊的加权评分抵消硬失败：

```ts
const delivered = samples.filter((sample) => sample.successfulDelivery);
const identity = samples.filter((sample) => sample.identityApplicable);
const totalCost = samples.reduce((sum, sample) => sum +
  sample.inferenceCostYuan + sample.moderationCostYuan + sample.retryCostYuan +
  sample.storageCostYuan + sample.bandwidthCostYuan + sample.paymentFeeYuan +
  sample.refundLossYuan, 0);
const totalRevenue = delivered.reduce((sum, sample) => sum + sample.candidatePriceYuan, 0);
const contributionPerDelivery = delivered.length === 0
  ? Number.NEGATIVE_INFINITY
  : (totalRevenue - totalCost) / delivered.length;

const decision = gates.every((gate) => gate.passed) ? "GO" : "NO_GO";
return { decision, sampleCount: samples.length, successfulDeliveryCount: delivered.length, metrics, gates };
```

- [ ] **Step 3: 实现稳定 Markdown 报告**

输出顺序固定为：标题、判定、样本数、指标表、门禁表、限制说明。比例统一显示一位小数百分比，金额显示两位小数；禁止包含原始输入 JSON。

```ts
export function renderMarkdownReport(report: GateReport): string {
  const gateRows = report.gates.map((gate) =>
    `| ${gate.id} | ${gate.actual} | ${gate.operator} ${gate.threshold} | ${gate.passed ? "PASS" : "FAIL"} |`
  );
  return [
    "# V1 真实质量与成本门禁报告",
    "",
    `- 判定：${report.decision}`,
    `- 样本数：${report.sampleCount}`,
    `- 成功交付数：${report.successfulDeliveryCount}`,
    "",
    "| 门禁 | 实际值 | 阈值 | 结果 |",
    "|---|---:|---:|---|",
    ...gateRows,
    "",
    "> 本报告只证明输入数据对应的离线门禁结果，不等于产品可发布。"
  ].join("\n");
}
```
