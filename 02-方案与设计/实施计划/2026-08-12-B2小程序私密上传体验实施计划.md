# B2 小程序私密上传体验 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为现有微信小程序增加单张照片私密选择、预签名 PUT 直传、有限重签、异步状态查询和安全恢复体验。

**Architecture:** 上传协议、传输适配和安全恢复集中在 `services/upload.ts`，页面只管理可展示状态。首页通过隐私页的受控 `next=upload` 路径进入上传页，确保选择本地照片前完成当前政策同意与登录；上传页不持有对象键，不持久化文件路径、凭证或签名 URL。

**Tech Stack:** TypeScript 5.9、微信小程序原生 Page/WXML/WXSS、Vitest 3.2、现有 `@photo-ai/contracts` 与 `authenticatedRequest`。

## Global Constraints

- 文件上限严格为 `30 * 1024 * 1024` bytes；首版只接受 `.jpg`、`.jpeg`、`.png`、`.heic`、`.heif`。
- 后端上传目标是预签名 `PUT`；不得误用只提供 multipart 语义且无 `method` 参数的 `wx.uploadFile`。
- PUT 传输通过独立 `UploadTransport` 边界实现；微信适配器使用 `wx.getFileSystemManager().readFile` 取得 `ArrayBuffer` 后调用 `wx.request({ method: "PUT" })`。
- 30 MB 文件的真机内存峰值尚未验收，必须在 Task 9 保持 `NOT ACCEPTED`；若真机失败，再评估 COS POST policy 或受控 SDK，不在本任务静默扩展依赖。
- 只有当前时间已达到服务端 `credentialExpiresAt` 且上传返回 `401/403` 时，才自动重签一次；普通断网、超时、未知 `5xx` 或过期前的 `403` 不重签。
- 永久存储只允许 `{ sessionId, state, updatedAt }`；不得存储本地照片路径、二进制、对象键、临时凭证、上传 URL、请求头或供应商响应。
- 用户文案不得出现 COS、CI、腾讯、供应商置信度、内部对象键或原始异常；失败必须说明“本次未扣除免费次数或积分”。
- 不调用真实 COS/STS/CI，不启动微信开发者工具，不使用正式 AppID；真实环境验收属于 Task 9。
- 不新增运行时依赖，不重构无关页面，不修改后端上传协议。
