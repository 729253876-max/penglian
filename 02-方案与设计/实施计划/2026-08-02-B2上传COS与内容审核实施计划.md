# B2 上传、COS 与内容审核 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 B1 身份体系之上，实现私有 COS 短期直传、服务端真实校验、规范化副本、内容审核、持久化作业和小程序上传恢复，并保证失败或拒绝不创建修图任务、不扣权益。

**Architecture:** API 创建 30 分钟上传会话并签发 10 分钟最小权限 COS 凭证；小程序直传私有 COS；API 校验对象归属后在 MySQL 事务中创建规范化/审核作业；独立 Worker 以租约领取作业，调用可替换的对象存储、图像规范化和审核接口。腾讯云适配器与模拟适配器共享契约测试。

**Tech Stack:** TypeScript、Node.js、Fastify、Zod、MySQL 8、`mysql2`、腾讯云 COS/STS/数据万象/内容审核 REST API、Vitest、微信原生小程序。

## Global Constraints

- 接受 `JPEG/JPG`、`PNG`、`HEIC/HEIF`；服务端以文件魔数和真实解码结果为准。
- 单文件最大 30MB；短边至少 256px；长边最多 12,000px；总像素最多 50MP。
- 短边低于 1,024px 可继续但提示质量风险；透明 PNG 不静默铺白。
- 元数据清理必须已显式授权；未授权不签发上传凭证。
- 上传会话 30 分钟；COS 临时凭证 10 分钟；会话有效时最多重新签发一次。
- 原始 COS 对象保持私有；规范化副本应用旋转和 sRGB，且不向审核或供应商发送原始 EXIF。
- 原图长边超过 10,000px 时生成最长边不超过 10,000px 的审核副本。
- 疑似违规自动复核一次；审核服务故障最多 3 次、总等待不超过 5 分钟；V1 无人工原图复核。
- 原图与低清预览保存 7 天；真实删除执行由 B4 完成，B2 必须写入到期时间和清理作业。
- 不引入 Redis、Kafka、境外运行时 SaaS或本地内存队列。
- 任何真实 COS、内容审核、密钥、资源开通或费用动作必须先征求用户同意。
