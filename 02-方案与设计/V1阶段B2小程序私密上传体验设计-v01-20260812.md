# V1 阶段 B2 小程序私密上传体验设计

> 版本：v01
> 日期：2026-08-12
> 状态：用户已批准设计方向，待实施
> 适用任务：B2 Task 8「小程序选择、直传、恢复和提示」

## 1. 目标与范围

在现有示例体验之外增加真实照片入口，让用户在理解隐私处理后完成单张照片选择、私密直传、服务端确认和异步检查，并能从可恢复状态继续。

本任务包含：

- 首页新增“上传自己的照片”入口，保留现有示例入口。
- 独立上传页与上传服务。
- JPEG、PNG、HEIC/HEIF 的本地扩展名和 30 MB 上限预检。
- 创建上传会话、COS 直传、完成确认、状态轮询和有限恢复。
- 全部用户可见失败与终态文案。
- 只持久化会话 ID 与安全状态，不持久化临时凭证、签名 URL、对象键或供应商响应。

本任务不包含：

- 分片或断点续传、批量上传、后台持续上传。
- 真实腾讯 COS/CI、正式 AppID、真机弱网和供应商效果验收。
- 计费、积分扣减、支付或发布。

## 2. 已确认事实与未验证边界

已确认：

- 后端已提供创建会话、重签凭证、完成上传、查询状态和取消会话接口。
- 完成接口只确认对象并入队，返回 `202`，不会同步执行图像供应商处理。
- 会话与对象键均由服务端生成；跨用户访问隐藏为 `404`。
- 小程序已有受保护请求与会话刷新能力。

未验证：

- 微信真机对目标 COS PUT、响应头和 ETag 的实际暴露方式。
- COS/STS 的真实凭证签发与过期错误表现。
- 真实弱网、切后台、杀进程和不同系统相册返回字段。

以上未验证项必须保留到 Task 9 真实环境门禁，不作为 Task 8 完成声明。

## 3. 方案选择

采用独立单页可恢复上传方案：

- 首页承担入口选择，不承载上传状态机。
- 上传页承担隐私说明、照片选择、进度、检查和恢复。
- `services/upload.ts` 封装协议解析、状态持久化和恢复策略，页面只消费稳定的领域结果。

不采用首页内嵌上传，因为首页会同时承担示例、授权和多阶段错误状态，维护和测试成本过高。不采用多页向导，因为首版单张上传不需要额外导航层级，步骤过多会降低完成率。

## 4. 用户流程

1. 首页点击“上传自己的照片”。
2. 进入上传页，先看到三条明确说明：私密上传、会移除定位/设备等元数据、失败不扣次数或积分。
3. 用户主动点击“选择照片”，调用相册/相机选择单张原图。
4. 本地预检扩展名与文件大小；失败时不创建服务端会话。
5. 使用当前已同意隐私政策的登录会话创建上传会话。
6. 使用临时上传凭证直接上传对象。
7. 仅在能够确认“上传凭证失效”的响应时重签一次并重传；普通网络失败不重签。
8. 从可信响应取得 ETag，调用完成接口。
9. 持久化 `{ sessionId, state, updatedAt }`，轮询服务端状态。
10. 进入可精修状态时清除恢复记录并进入后续流程；终止、取消或会话过期时清除恢复记录。

## 5. 状态与恢复

页面状态：

- `IDLE`：等待选择。
- `VALIDATING`：本地检查。
- `CREATING`：创建服务端会话。
- `UPLOADING`：直传原图。
- `CONFIRMING`：提交 ETag。
- `PROCESSING`：归一化和安全检查。
- `READY`：允许继续精修。
- `WARNING`：质量有限但允许继续。
- `RECHECKING`：安全复检中。
- `FAILED`：可重试或重新选择。

安全持久化结构只包含：

```ts
type StoredUploadResume = {
  sessionId: string;
  state: "UPLOADED" | "PROCESSING";
  updatedAt: string;
};
```

页面加载时查询该会话的服务端状态。若仍在处理中则继续轮询；若会话需要重新上传，要求用户重新选择本地文件，不保存本地临时路径作为跨启动恢复依据。

## 6. 上传与重试边界

- 文件上限为 30 MB，使用 `<= 30 * 1024 * 1024`。
- 首版允许 JPEG、PNG、HEIC、HEIF；实际内容与像素边界仍由服务端规范化阶段判定。
- 临时上传凭证最多自动重签一次。
- 只有明确的鉴权/签名过期响应可触发重签；超时、断网、DNS 和未知 5xx 不触发重签。
- 完成接口的 `409 UPLOAD_ETAG_MISMATCH` 要求重新上传，不自动循环。
- 轮询使用有界间隔并在页面隐藏时停止，页面恢复后重新查询；不使用阻塞等待。
- 用户取消只请求服务端取消可取消状态，并清理本地恢复记录。

## 7. 用户文案

所有失败文案都附带“本次未扣除免费次数或积分”，且不显示供应商、置信度、对象键或内部错误详情。

| 场景 | 用户文案 |
| --- | --- |
| 文件过大 | 这张照片超过 30 MB，请选择更小的原图。本次未扣除免费次数或积分。 |
| 格式不支持 | 目前支持 JPG、PNG、HEIC 和 HEIF，请重新选择。本次未扣除免费次数或积分。 |
| 像素边界失败 | 照片尺寸不适合处理，请换一张更清晰的原图。本次未扣除免费次数或积分。 |
| 质量警告 | 照片清晰度或曝光有限，仍可继续，但改善幅度可能受限。 |
| 安全复检 | 照片正在进一步检查，完成后会自动更新。 |
| 安全拒绝 | 这张照片暂时无法处理，请更换照片。本次未扣除免费次数或积分。 |
| 会话过期 | 本次上传已过期，请重新选择照片。本次未扣除免费次数或积分。 |
| 网络/服务失败 | 上传暂时没有完成，请检查网络后重试。本次未扣除免费次数或积分。 |

## 8. 组件边界

`services/upload.ts`：

- 严格解析 API 响应和 COS 上传结果。
- 执行本地校验、会话创建、上传、一次凭证重签、完成确认和状态查询。
- 管理安全恢复记录。
- 将内部/API 错误映射为稳定的页面错误码。

`pages/upload/index.ts`：

- 管理页面状态和生命周期。
- 响应选择、重试、取消、继续精修。
- 不保存或展示凭证、签名 URL、对象键和供应商信息。

首页仅导航；后续精修页继续沿用现有任务/预览边界，不在本任务内重构。

## 9. 测试与验收

自动化门禁：

- 30 MB 允许，30 MB + 1 拒绝。
- 不支持格式在任何网络调用前拒绝。
- 明确凭证过期时只重签一次、上传两次。
- 普通网络失败不重签。
- 完成调用携带可信 ETag，且不把对象键交给客户端决定。
- 本地存储不出现凭证、签名 URL、对象键或照片路径。
- 恢复时只查询已保存会话，不自动访问相册或上传。
- 所有终态文案不出现供应商名或置信度，并说明失败不扣次数/积分。
- 微信 TypeScript 构建、运行时同步检查和全 workspace 测试通过。

真实环境门禁：

- 微信开发者工具、正式 AppID、Android/iOS 真机、真实 COS/STS、真实 ETag、弱网和后台恢复必须在 Task 9 另行授权和验收。

## 10. 回滚与维护

- 首页入口、上传页注册和上传服务为独立增量，可通过单个提交回滚。
- 上传 API 响应解析集中管理，后端字段变化只需调整一个边界。
- 恢复记录带固定版本化键；结构变化时清理旧值，禁止猜测迁移临时凭证。
- 不引入新的运行时依赖，不增加长期凭据或本地后台任务。
