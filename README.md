## 范围

- 本次包含：V1 的 AI 智能人像精修、画质增强、路人/杂物消除、老照片修复，以及与项目目标直接相关的任务和文件。
- 老照片修复默认处理划痕、褪色、噪点、轻度模糊和局部破损，忠实保护人物身份、服饰、年代感和原构图；“修复并上色”仅在用户主动选择并显式确认后执行，不得宣称缺乏依据的细节为真实历史还原。
- 本次不包含：AI 抠图、创意模式（第二阶段）、纯问答、其他项目内容和可安全再生成的系统缓存。
